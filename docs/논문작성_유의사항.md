# 논문 작성 유의사항 (HCLT 2025 템플릿 정리)

> 출처: 업로드된 템플릿 `hclt.sty`, `hclt.tex`, `IEEEtran.bst`에 적혀 있던 규정·안내를 모두 모음.
> 학술대회: **2025년도 한글 및 한국어 정보처리 & 한국코퍼스언어학회 공동 학술대회**.
> 편집: pdflatex 계열. Overleaf면 **TeX Live 2021**로 설정 권장(`Menu → TeX Live version`).

---

## 1. 분량·용지 (가장 먼저 확인)

- **페이지 수: 2쪽 이상 6쪽 이내.**
- **구두발표는 3쪽 이상** 작성해야 함.
- 용지: **A4, 가로쓰기, 2단(two-column), 10pt.**
- 여백: **위 30mm · 아래 20mm · 좌 10mm · 우 10mm.**

## 2. 암행평가(blind review) — 저자정보 절대 금지

- 심사용 논문에는 **저자 정보(이름·소속·이메일)를 일절 표기하지 않는다.**
- 템플릿은 저자 정보를 입력해도 기본값(`성명/소속/이메일`, `Anonymous Author(s)/Affiliation`)으로 출력됨.
- **최종본(카메라레디)에서만** 문서 상단의 `\finalcopy` 주석을 해제 → 실제 저자 정보 출력.
- **감사의 글도 심사용엔 표기하지 않는다** — `\section*{감사의 글}` 부분을 주석 처리.
- 발표자는 공동저자와 구분: **`\circ`(°) 기호**로 표기.

## 3. 제목·저자·요약·주제어

- 제목: 국문·영문 둘 다. `\title[korean]{...}`, `\title[english]{...}`.
- 저자: `\author[korean]{...}`, `\author[english]{...}`.
- **요약(Abstract):** `\begin{abstract}...\end{abstract}`. 연구 목적·방법·주요 결과·의의를 간결·명확히, 핵심을 함축.
- **주제어(Keyword):** `\begin{keyword}...\end{keyword}` (빨간색 "주제어:"로 출력). 쉼표로 나열.
- 제목·저자·요약·주제어는 `\twocolumn[ ... ]` 안에 넣어 단 상단 전체폭으로.

## 4. 장·절 구조

- `\section` (1.), `\subsection` (1.1), `\subsubsection` (1.1.1). **번호는 아라비아 자동.**
- 절 간격이 좁게 설정돼 있으니 그대로 사용.
- (참고) 정리/증명/명제 환경 제공: `theorem`(정리), `proof`(증명), `proposition`(명제), `lemma`, `definition`.

## 5. 글머리표

- **숫자 없는 목록:** `\begin{itemize} \item ... \end{itemize}`.
- **숫자 있는 목록:** `\begin{enumerate} \item ... \end{enumerate}`.

## 6. 수식

- `\begin{eqnarray} ... \label{eqn:xxx} \end{eqnarray}`, 참조는 `\eqref{eqn:xxx}`.
- 번호 생략: 해당 줄에 **`\nonumber`**.

## 7. 그림·표 (캡션 위치 주의)

- **표:** `\begin{table}[t] \caption{...}\label{tab:...} \begin{center}\begin{tabular}...\end{tabular}\end{center} \end{table}`.
- **그림:** `\begin{figure}[t] \centering \includegraphics[width=.4\textwidth]{파일} \caption{...}\label{fig:...} \end{figure}`.
- **캡션 위치: 그림은 하단, 표는 상단.**
- 참조: `\ref{fig:...}`, `\ref{tab:...}`. **참조 번호는 본문에서 언급된 순서대로 자동 부착.**
- 2단이라 그림은 보통 `width=.4~.46\textwidth`(단 폭). 전체폭이 필요하면 `figure*`/`table*`.

## 8. 자동 조사 (한국어 kotex)

참조 번호에 따라 조사가 바뀌므로 **직접 쓰지 말고 자동조사 명령**을 쓴다.
예: `그림 \ref{fig:cat}\은` → 번호에 맞는 은/는 자동 선택.

지원 조사 **12가지:**
`\이 \가 \을 \를 \와 \과 \로 \으로 \은 \는 \라 \이라`

> 표·그림을 중간에 추가해 번호가 바뀌어도 조사를 일일이 안 고쳐도 됨.

## 9. 참고문헌 (IEEEtran)

- 스타일: **`\bibliographystyle{IEEEtran}`**, `\bibliography{refer}`.
- 인용: **`\cite{key}`**. 여러 개는 콤마로: `\cite{a,b,c}`.
- `refer.bib`에 BibTeX 엔트리 관리. 저자·제목·학술지·권·호·쪽수·발행년도 순으로 자동 기술.
- 컴파일 순서: `pdflatex → bibtex → pdflatex → pdflatex`.

## 10. 파일 구성 (기본 3 + 부속)

| 파일 | 역할 |
|---|---|
| `hclt.sty` | 스타일(양식) — 손대지 않음 |
| `hclt.tex` | 본문 작성 파일(우리는 `main.tex`) |
| `IEEEtran.bst` | 참고문헌 서식 |
| `refer.bib` | 참고문헌 BibTeX |
| (그림들) | `figures/` |

## 우리 논문에 바로 걸리는 체크리스트

- [ ] **6쪽 이내** (본문 ~5 + 참고문헌 ~1). 넘으면 안 됨.
- [ ] **저자 정보 비움**(심사용) — `\finalcopy` 주석 상태 유지, **감사의 글 주석**.
- [ ] 제목 국문·영문 둘 다, 요약·주제어 채움.
- [ ] 그림 캡션 **하단**, 표 캡션 **상단**.
- [ ] 본문에서 그림·표를 **언급 순서대로** 배치(참조 번호 자동).
- [ ] 조사는 **자동조사 명령** 사용.
- [ ] 참고문헌 `\cite` + `refer.bib`, IEEEtran 스타일.
- [ ] 2단 그림 폭 `~.46\textwidth`, 필요시 `figure*`.

> 이 문서는 템플릿 규정만 모은 것. **논문 본문(글)은 연구자가 직접 작성한다.**
