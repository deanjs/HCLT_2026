## 1. 왜 이 실험을 하나

step4는 "지침을 본다"까지였다. 보는 것과 **따르는 것**은 다르다.

**RQ3(인과) — 지침 신호도 코드와 같은 통로(내용/Value)인가?**

step3의 지침 판이다. 장치가 완전히 같고 **치환 대상만 다르다.**

| | step3 | step5 |
|---|---|---|
| 바꾸는 곳 | 선행 코드의 **위반 이름 6개** | 지침의 **지시어 단어 1개** |
| 공여 | 같은 이름의 준수판 | **반대 지침**의 지시어 |
| 구간 종류 | `def_name` | `literal` |

## 2. 무엇을 건드리나

```
   base 프롬프트:
   "In this project we generally write function names in camelCase."
                                                          ^^^^^^^^^
                                                          여기 캐시만 교체
   반대 지침 프롬프트:
   "In this project we generally write function names in snake_case."
                                                          ^^^^^^^^^
                                                          여기서 가져온다
```

**글자는 `camelCase` 그대로 두고, 모델 속 값만 `snake_case`의 것으로 바꾼다.**
그러고 나서 모델이 어느 표기를 선호하는지 본다.

### 위치가 정확히 일치한다

두 프롬프트는 지시어 단어를 빼면 **완전히 같다.**

```
   base:     "You are helping extend an existing Python module.\nIn this project we generally write function names in camelCase."
   opposite: "You are helping extend an existing Python module.\nIn this project we generally write function names in snake_case."
              └────────────────── 103번째 글자까지 동일 ──────────────────┘
```

→ 덮을 자리와 공여 자리의 **시작 위치가 같다**(진단 A에서 어긋남 0.5칸 이하 확인).
step3보다 위치 조건이 깨끗하다.

## 3. 재는 값

```
   S = log P(지침 목표 표기 이름) − log P(반대 표기 이름)
```

> **부호 주의.** `logP(camel) − logP(snake)`가 **아니다.**
> 목표 표기 기준이므로 snake 지침 조건에서는 부호 관계가 뒤집힌다.
> 실데이터로도 확인: snake 목표 조건은 `S_base > 0`이 168개 중 148개,
> camel 목표 조건은 `S_base < 0`이 138개.

```
              S_개입 − S_기준
   전이율 = ──────────────────
              S_반대 − S_기준

   S_기준 : 조건 지침 그대로 (camel 지침)
   S_반대 : 반대 지침을 실제로 준 상태 (snake 지침) — 천장
   S_개입 : camel 지침인데 지시어 KV만 snake 것으로 교체
```

**1 = 반대 지침을 실제로 준 것과 같은 수준까지 넘어갔다.**

## 4. 통제 — 세 종류

| 공여 | 지시어 자리에 넣는 것 | 표기 정보 | 정상이면 |
|---|---|---|---|
| **반대 지침** (처치) | 반대 지침의 지시어 | 들어감 | 크게 넘어감 |
| **자기 통제** | **같은 지침의 같은 지시어** | **안 들어감** | ≈ 0 |
| **지시어 절제** | 같은 지침의 무관한 단어(`project`) | 안 들어감 | — |

**순효과 = 처치 − 자기 통제.**

자기 통제는 내용이 그대로이므로 순수하게 "덮어쓰는 행위 자체"의 몫(거품)이다.
(완전한 항등은 아니다 — 자기 조각들을 평균 내 다시 넣으므로 약한 평탄화가 일어난다.)

> **절제 조건은 통제가 아니다.** 지시어 자리를 `project`로 덮으면 **지침이 지워진다.**
> 그러면 모델이 "지침 없는 상태"로 가는데, 그 방향이 마침 반대 지침 쪽과 같다.
> 그래서 값이 크게 나온다(0.27~0.45). 이건 거품이 아니라 **"지시어를 없애면 어떻게 되나"** 를
> 따로 보는 실험이다.

## 5. 파이프라인

```
Condition(target="instruction", donor=..., kinds=(key,value,key_value))
   │
   ▼
_preference_setup_instruction()
   │  base_system   = 조건 지침
   │  opp_system    = 반대 지침 (선행 코드는 공유)
   │  viol_names    = ["camelCase"]        ← 덮을 단어
   │  donor_names   = ["snake_case"] 또는 ["camelCase"] 또는 ["project"]
   ▼
handle.intervene_preference_sweep(span_kind="literal")
   │
   ├─ literal: 그 문자열의 **첫 등장**을 찾는다
   │           (규칙문이 후보열거보다 앞서므로 첫 등장 = 실제 지시어)
   └─ 나머지는 step3와 완전히 동일
   │
   ▼
Metrics.per_layer[L]["value__recovery"] 등
```

함수 단위 해설·호출 사슬·실제 코드 발췌는 **[`code.md`](code.md)** 에 있다. 여기서는 방법만 다룬다.

## 8. 처음과 달라진 것

| # | 처음 | 지금 | 왜 |
|---|---|---|---|
| **설계** ⭐ | **통제 조건 0종** | **자기 통제 + 절제 2종 추가** | step3에서 거품이 절반 이상이었는데 step5엔 통제가 없어 크기를 말할 수 없었다 |
| **분석** | camel·snake 방향을 **합쳐서** 평균 | **방향별로 분리** | StableCode가 camel 0.45 / snake 1.32로 3배 차이. 평균 0.89는 두 분포를 섞은 값이고 84개 중 38개가 전이율 1을 넘는다 |
| **서술** | `S = logP(camel) − logP(snake)` | **`logP(목표 표기) − logP(반대 표기)`** | snake 목표 조건에서 부호가 뒤집힌다. 이대로면 재현자가 계산을 틀린다 |
| **서술** | "코드 층 ≈ 지침 층 (1~3층 차이)" | **철회** | step3는 camel 한 방향, step5는 양방향 평균 — 조건 집합이 다른 두 봉우리를 맞댄 것이었다. 대신 **step4 관측 ↔ step5 인과** 일치로 대체(3모델 정확히 같은 층) |
| **분석** | 판정 불가 기준 1.0을 노트북 지역 상수로 | **하네스 규약 + 민감도 표** | 기준을 0.5/1.0/2.0 어디에 둬도 전이율은 불변임을 확인 |
| **해석** | 무관 단어를 "음성 통제"로 | **"절제 실험"으로 재해석** | 지시어를 지우면 지침이 무력해지고, 그 방향이 반대 지침 쪽과 같다. 방식 간 차이도 없다(0.415 vs 0.443) |
| **코드** | 층 목록을 주면 첫 층만 | **예외** | 통제를 봉우리−3층에서 재는 사고가 실제로 났다 |
| **코드** | 통제를 K+V 방식으로만 측정 | **세 방식 동시**(`Intervention.kinds`) | 본실험 헤드라인은 Value 단독인데 K+V 거품을 뺄 수 없다 |

## 9. 이 스텝의 한계

- **규칙문 지시어 한 곳만** 바꾼다. 후보열거의 같은 단어는 남아 효과가 희석될 수 있다
- 긍정형·약한 어조 고정. 부정형은 스키마에 있으나 실행하지 않았다
- 채점 대상은 고정된 이름 **한 쌍**
- 자기 통제는 완전한 항등이 아니다(약한 평탄화, 내용 쪽 0.05~0.09가 그 크기)
- step3와 봉우리 층을 직접 비교하지 않는다(조건 집합이 다르다)
