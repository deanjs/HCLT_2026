# step A-2 결과 — 실제 저장소 코드 (1차 실행)

**실행:** Qwen2.5-Coder-3B-Instruct (fp16). 12조건 = 2 언어 × 3 실파일 × 2 지침(camel/snake).
선행 = **실제 파일 원문**(CPython PSF · axios MIT, `data/repo_files/`). 개입 없음.
결과 원본: `results/stepA-2/*.json` (불변, §6).

**대응 RQ:** RQ1 외적 타당성 — 합성이 아닌 실코드에서도 성립하는가.

## 예측 (실행 전)

> 일치 칸(파일 관습=지침) 높음, 충돌 칸 낮음이면 언어 관습(형태)이 지침을 압도.

## 관측 결과 — 준수율 2×2

| 선행 파일 | 지침=camel | 지침=snake |
|---|---|---|
| **Python** (자연 snake) | 0.00 | 0.67 |
| **JavaScript** (자연 camel) | 0.67 | 0.00 |

(0.67이 1.0이 아닌 건 생성 과제 1 `clamp`→"other" 때문. 그 턴 빼면 aligned 칸은 사실상 1.0.)

## 핵심 관측 — 지침은 완전히 불활성

조건별 원문에서 **지침이 camel이든 snake이든 출력이 글자까지 동일**하다:

- **Python 파일** → 지침과 무관하게 항상 `count_vowels`, `merge_dictionaries` (**snake**)
- **JavaScript 파일** → 지침과 무관하게 항상 `countVowels`, `mergeDictionaries` (**camel**)

같은 파일이면 지침 camel/지침 snake의 생성 결과가 **바이트까지 같다.** 표의 0.67 vs 0.00 차이는 "파일 관습이 지침과 우연히 일치했는가"일 뿐, **모델 행동은 지침에 0 반응**이다.

## 해석

1. **지침(논리 제약)이 이름 결정에 기여하는 바가 0.** camel 지침 vs snake 지침 → 동일 출력.
2. **"snake prior 탓"이 아니다.** JS 코드에선 모델이 **camel**을 낸다. 고정 편향이 아니라 **주변 코드의 관습을 따라가는 것**(form-matching): Python→snake, JS→camel.
3. **A·A-1·A-2가 하나로 합쳐진다:**
   > 모델은 함수 이름 짓기를 **"주변 코드의 표기 관습에 맞추는 일"**로 처리한다. 지침은 불활성.
   - step A(clone): 문맥이 snake 다수 → snake 바닥
   - A-1(distinct): 베낄 같은-과제 예시 없음 → prior(snake) 회귀, camel 0
   - **A-2(실코드): 파일 관습이 곧 출력** — Python→snake, JS→camel, 지침 무시

실코드 + JS 헤드룸 덕분에 "prior냐 관습이냐" 혼동이 제거된, **가장 깨끗한 형태-지배 증거**다.

## RQ1 답

준수 실패의 정체는 "지침을 못 따름"이 아니라 **"주변 형태 관습을 따름"**이다(실코드에서도 성립). 지침은 불활성. → 매개 신호가 형태라는 RQ2로 자연 연결.

## 한계

- **약한 지침 하의 결과.** 지침은 system 한 줄·약한 어조("we generally write…")다. "형태로 처리돼 불활성"인지 "약해서 무시"인지는 이 데이터만으론 못 가른다. 단, 이는 CLAUDE.md류 **현실적 약한 규약**을 모델화한 것이며, "지침이 **형태로** 처리된다"의 직접 증명은 어조(strength)가 아니라 **부정형(RQ3)**이 담당한다.
- **표본:** 언어당 파일 3개(셀당 3). 결과가 완전 이분적(지침 무관 동일 출력)이라 방향은 확정적이나, 논문용으론 파일 수를 늘려 만장일치를 재확인하는 것이 좋다.
- **과제 설계:** 생성 과제 1 `clamp`가 한 단어로 축약돼 "other"(1/3 턴). 나머지 두 턴은 만장일치라 결론 불변. 첫 과제 교체 필요.
- 부수 관측: `merge`를 한 파일에선 `mergeObjects`로 지음(파일 문맥이 **의미어 선택**까지 물들임) — 형태뿐 아니라 어휘도 문맥에 좌우.
