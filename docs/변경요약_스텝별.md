# 무엇이 바뀌었나 — 스텝별 한눈 정리

> **결론부터: 논문의 방향은 바뀌지 않았다.**
> 큰 주장("문제도 손잡이도 어텐션이 아니라 내용(Value)에, 후반 특정 층에 있다")은 그대로다.
> 바뀐 것은 **문장 3개와 수치 표기 방식**이고, 그중 둘은 주장을 **강하게** 만든다.
> 새로 돌려야 하는 실험은 **2건**이며 둘 다 전 층 스윕이 아니다.

---

## 0. 큰 그림 — 뼈대는 그대로

| 논문의 주장 | 상태 |
|---|---|
| 문맥의 규약 위반이 준수를 무너뜨린다 (RQ1) | **유지** |
| 코드의 표기 신호는 **내용(Value)** 에 실린다 (RQ2) | **유지 · 더 강해짐** |
| 그 신호는 **후반 특정 한 층**에 국소화된다 (RQ2) | **유지 · 더 선명해짐** |
| 지침 신호도 같은 통로(내용)다 (RQ3) | **유지 · 통제로 확정** |
| 모델이 지침을 **덜 봐서** 못 지키는 게 아니다 (Spotlight 반박) | **유지 · 더 강해짐** |
| ~~내용만으로 충분하다, 어텐션은 잉여다~~ | **철회** ← 유일하게 잃은 것 |

## 1. 스텝별 표

### step1 — 준수율 절벽 (RQ1)

| | |
|---|---|
| **기존** | 위반 5개에서 준수율이 절벽처럼 무너진다. 파이썬 관습과 부딪히는 camel 방향에서만 나타난다 |
| **바뀐 것** | **주장 유지.** 두 가지만 덧붙음: ① 절벽 아래는 완만한 감소가 아니라 **정확히 0.000** ② **자기증폭 지표는 측정된 적이 없다** |
| **왜** | 결과 2184개 전부 `turn_notations`에 **생성 턴이 1개뿐** → 뒤따르는 함수가 없어 "첫 함수가 위반이면 뒤도 위반인가"를 잴 원자료가 없다 |
| **어떻게** | 절벽은 재집계로 재확인(GPU 0). 자기증폭은 **주장에서 빼거나** 3턴 생성으로 재실행 |
| **GPU** | **불필요**(절벽) / **선택**(자기증폭을 논문에 쓸 경우에만) |

### step2 — 코드 관측 (RQ2)

| | |
|---|---|
| **기존** | 후반 층에서 snake 구간을 camel 구간보다 더 본다 |
| **바뀐 것** | **주장 철회.** 자리 효과였다. Qwen·Llama는 배치를 뒤집자 **부호까지 뒤집힌다** |
| **왜** | 표기 배치를 묶음이 아니라 **시드**가 정해(`prompt.py:151`) 42묶음 전부 배치가 같았다. 어텐션은 프롬프트 순서를 따라 떨어지고 시드 42에서는 위반이 1번 자리다 — "위반을 본다"와 "앞자리를 본다"가 100% 겹쳤다 |
| **어떻게** | 시드 42의 **정확한 여집합**(12/12 반대)인 시드 67을 새로 돌려(166조건) 같은 묶음끼리 짝지어 평균 → 자리 항이 식에서 소거된다 |
| **결과** | 두 시드 평균: qwen **+0.00003±0.00050**(0을 문다) · llama **−0.00005±0.00009**(0을 문다) · deepseek +0.00088 · stability +0.00063. 남은 두 모델도 **유의하게 음수인 층이 양수 층의 2~4배**이고 격차가 후반이 아니라 **앞~중간 층**에 있다 |
| **함께 무너진 것** | `‖a·v‖`도 어텐션을 곱하므로 같이 무너진다(qwen 11%·llama 3%, deepseek는 **음수로 뒤집힘**). `‖v‖`만 90~110% 남아 **음성 통제** 노릇을 한다 → 교란이 **어텐션 경로**로 들어왔다 |
| **먼저 있던 정정(유지)** | 수치가 **합 기준**임을 명시하고 토큰당 평균으로 재계산. `‖a·v‖`는 "실제 기여량"이 아니라 **상한** |
| **RQ에 미치는 영향** | RQ2의 답은 **step3(인과)가 전담**한다. 인과 스텝은 처치·통제가 **같은 자리**를 건드려 이 교란을 안 받는다 |
| **GPU** | 시드 67 실행분 필요 (완료) |

### step3 — 코드 인과 (RQ2) ← 가장 많이 바뀐 곳

| | |
|---|---|
| **기존** | 내용만 0.54 / 어텐션만 0.39, 차이 **+0.15**. "둘다 ≈ 내용만이니 **내용이 충분하고 어텐션은 잉여**" |
| **바뀐 것 ①** | **어텐션이 나른 표기 정보는 0이다** (순효과 −0.005~0.021, 내용의 2~11%) → **주장이 세짐** |
| **바뀐 것 ②** | **"어텐션은 잉여" 철회.** 순효과로는 둘다(0.117)가 내용만(0.253)의 **절반 이하** → **주장 하나 잃음** |
| **왜** | **통제를 빼지 않았다.** 무엇을 덮든 생기는 교란(거품)이 회복률의 절반 이상이었다. 어텐션은 camel을 덮든 snake를 덮든 값이 같다(0.374 vs 0.379) = 정보가 하나도 안 들어감 |
| **어떻게** | 규격이 동일한 두 통제(다른camel/다른snake)로 짝맞춤 재집계. 봉우리 층·분할검증 모두 통과 |
| **GPU** | **불필요**(재집계 완료) / **필요**: Key 위상 진단 — "둘다가 내용만보다 낮다"가 어텐션 경로의 성질인지 우리 조작의 고장인지 갈라야 한다 |

### step4 — 지침 관측 (RQ3)

| | |
|---|---|
| **기존** | 토큰당으로 보면 지침 지시어를 코드 이름보다 더 본다(qwen 1.55배 등) |
| **바뀐 것** | **아무것도 안 바뀜 — 독립 재확인됨.** 덤으로 **step4 관측 봉우리 = step5 인과 봉우리** 발견 |
| **왜** | (문서는 처음부터 옳았다. 잘못된 건 **노트북 요약 셀** — 아직 미정규화 + 초판 합산키를 쓴다) |
| **어떻게** | 합 기준 대조표를 부록에 추가(정규화 근거), 노트북 셀 교체 |
| **GPU** | **불필요** |

### step5 — 지침 인과 (RQ3)

| | |
|---|---|
| **기존** | 전이율 0.42~0.89, 어텐션만은 0.11~0.23. "코드 층 ≈ 지침 층(1~3층 차이)" |
| **바뀐 것 ①** | **StableCode를 방향별로 분리.** camel 0.45 / snake 1.32 (평균 0.89는 두 분포를 섞은 값, 84개 중 38개가 1 초과) |
| **바뀐 것 ②** | **"코드 층 ≈ 지침 층" 철회** |
| **바뀐 것 ③** | 전이율 **크기**는 상한으로만 서술 |
| **왜** | ① 방향 비대칭이 3배 ② step3는 camel **한 방향**, step5는 **양방향 평균** — 조건 집합이 다른 두 봉우리를 맞댄 것 ③ **통제 조건이 하나도 없어** 거품을 못 뺀다 |
| **어떻게** | 방향 분리·중앙값 병기·기준선 민감도 재집계(완료). 층 일치 주장은 **step4↔step5**로 대체(3모델 정확히 일치) |
| **GPU** | **불필요**(재집계 완료) / **필요**: 통제 공여 1종 추가 |


### step6 — 처방 (신규)

| | |
|---|---|
| **결과** | 값 조향은 세기 1~2에서 준수율 0.95~1.00 회복. Spotlight는 −0.37~0.27로 무효 |
| **핵심 발견** | **선호 점수가 준수율을 대변하지 않는다.** Qwen 세기4는 회복률 1.733인데 실제 준수율 0.000 — 나온 이름이 `RemoveDuplicates`(대문자 시작) |
| **Spotlight 방어** | 지시어 어텐션 비중이 0.002 → 0.231로 **실제로 올랐음을 기록** → "구현 실패" 반박 차단 |
| **철회** | 층 특이성 — 초반 층에 밀어도, 교차 주입해도 비슷하게 작동 |
| **범위 축소** | Llama는 Spotlight도 0.904로 작동 → "코드 특화 모델에서 무익"으로 좁힘 |
| **제외** | StableCode 생성 결과 — 무개입에서도 이름이 어긋나 측정 장치 문제로 판단 |
| **GPU** | 완료 |

## 4. 왜 갑자기 복잡해 보였나

바뀐 내용이 많아서가 아니라, **흩어져 있던 것을 한자리에 모았기 때문**이다.

- 결과가 **5개 브랜치에 나뉘어** 있어 어느 브랜치에서도 논문을 쓸 수 없었다 → 한 곳으로 모았다
- **하네스도 갈라져** 있어 step1의 JS 기능과 step4의 지시어 분리 기능이 통합본에 없었다 → 합쳤다
- 결과 폴더 이름이 규약과 달라 **하네스가 자기 결과를 못 읽었다** → 3528개를 규약 경로로 옮겼다

이건 논문 내용 변경이 아니라 **정리**다. 실험은 하나도 다시 안 돌렸다.
