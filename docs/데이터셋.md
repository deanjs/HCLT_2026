# 데이터셋 — 함수 이름 풀 (통일 재실험 기준)

표기 규약(camelCase / snake_case) 준수를 재는 데 쓰는 **합성 함수 이름 504개**의 구성과 한계를 정리한다.
설계·실험 순서는 `연구계획_통일재실험.md`.

---

## 1. 개요

| 항목 | 값 |
|---|---|
| 이름 수 | **504** |
| 생성 규칙 | 동사 50 × 명사 50 조합에서 중복 없이 504개 |
| 이름 형태 | 두 표기 — `parseHeader`(camel) / `parse_header`(snake) |
| 함수 본문 | 전 항목 동일 (`return value`) — **이름 표기만** 변수(통제) |
| 매개변수 | `value` (전 항목 동일) |
| 커버 방식 | 12개씩 42묶음으로 나눠 전부 사용 (묶음 = pool_block) |
| 무작위값(seed) | 42 (표기·배치 순서만 정함, 어느 이름인지는 묶음이 정함) |

## 4. 생성 과제 (모델이 이름을 직접 짓는 대상)

관측·측정용 이름(위 504개)과 별개로, 모델에게 **새 함수를 만들라**고 시킬 때 쓰는 과제 3개.
선행 코드의 이름과 겹치지 않는다(베끼기 혼입 방지).

| 과제 | 설명 | 규약형 / 위반형 |
|---|---|---|
| remove duplicates | 리스트 중복 제거 | `removeDuplicates` / `remove_duplicates` |
| count vowels | 문자열 모음 세기 | `countVowels` / `count_vowels` |
| merge dicts | 사전 둘 합치기 | `mergeDicts` / `merge_dicts` |

## 5. 표기 판정기

생성·문맥의 이름을 셋으로 분류한다.

| 분류 | 조건 | 예 |
|---|---|---|
| **camel** | 소문자로 시작 + 대문자 경계 1개 이상 | `parseHeader` |
| **snake** | 소문자로 시작 + 밑줄 경계 1개 이상 | `parse_header` |
| **other** | 둘 다 아님 (구분 불가) | `clamp`, `Parse`, `HTTP` |

## 6. 토크나이저·표기 한계점 (중요)

### (1) 한 단어 이름은 표기를 구분할 수 없다 — 그래서 전부 두 단어
`clamp` 같은 **한 단어**는 camel로 써도 `clamp`, snake로 써도 `clamp` → 완전히 같아서 **판정 불가("other")**.
실제로 초기 실험에서 생성 과제가 `clamp`였는데 모델이 한 단어로 축약해 표기를 못 쟀다.
→ **모든 이름(504개)과 생성 과제(3개)를 두 단어 이상으로 강제**해 camel≠snake가 항상 성립하게 했다.

### (2) 지시어(`camelCase`/`snake_case`)는 모델마다 토큰 수가 다르다
지침 속 표기 지시어 단어를 모델이 쪼개는 조각 수가 다르다(예: Qwen 2조각, deepseek 3~4조각).
→ 조각 수 1:1로 맞추는 방식(all)은 개수 안 맞으면 통째로 스킵된다.
→ **평균 덮어쓰기(mean-pool)** 로 통일: 반대쪽 조각을 평균 내 전 자리에 덮어써 개수 무관·스킵 없음.

### (3) 표기 마커가 담긴 위치가 코드와 지침이 다르다
- **코드 이름**: 표기 마커(대문자/밑줄)가 **마지막 토큰**에 몰림 (`parse|Header` vs `parse|_header`, 첫 토큰 공통).
- **지침 단어**: `camel|Case` vs `snake|_case` 처럼 **모든 토큰이 다름**(단어 전체가 표기 정보).
→ 그래서 코드는 마지막 토큰만 바꿔도 되지만, 지침은 단어 전체(평균 덮어쓰기)를 바꿔야 신호가 잡힌다.

### (4) 판정기가 "other"로 빠뜨리는 것
대문자로 시작(`ParseHeader`), 전부 대문자(`HTTP`), 표기 혼합(`parse_Header`), 한 단어는 모두 "other".
504 풀은 소문자 동사+명사 조합이라 항상 camel/snake로 깨끗이 갈리지만, **모델이 생성한 이름**이 이런
형태로 나오면 "other"로 집계된다(준수·위반 어느 쪽도 아님) — 준수율 계산 시 분리해 본다.

### (5) 언어별 함수 문법
표기 판정은 이름 문자열만 보므로 언어 무관하지만, 문맥 코드의 함수 문법은 언어마다 다르다
(파이썬 `def 이름(...)`, 자바스크립트 `function 이름(...)`). 기제 실험(step2~5)은 파이썬,
생성 실험(step1)만 파이썬+자바스크립트 2종을 쓴다.
