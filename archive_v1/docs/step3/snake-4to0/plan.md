# step3 · snake-4to0 — 절벽의 첫 하네스 재현 (RQ1 headroom)

> ⚠️ **폐기 (2026-08-11).** 이 실험의 생성 결과는 하네스 프롬프트 결함(이름 자유생성)으로 폐기됨 — 사유·재실행 조건: `results/step3_dispose/DISPOSED.md`.

**한 줄:** 지침을 **snake**로 돌려 Python 관습과 정렬(→ baseline 준수율 높음 = **headroom**)한 뒤, 준수(snake) 개수를 **4→0**으로 줄여 위반(camel) 선행이 준수율을 **절벽**으로 떨어뜨리는지 본다.

대응: **RQ1 보강** — headroom 판(지침=snake)에서 "선행 위반이 준수를 무너뜨린다"의 **첫 하네스 절벽 재현**. RQ3 아님(RQ3은 지침 Key/Value = step4).

## 무엇을 방어하나

step A(지침=camel, Python 코드)는 목표와 언어 관습이 충돌해 **바닥**이었고, 그래서 **절벽을 볼 수 없었다**(떨어질 높이가 없음). 또 전부 snake라 "자기 첫 선택 고수(자기증폭)"인지 "그냥 snake prior 지속"인지도 **분리 불가**였다.

지침을 snake로 두면 **모델 prior·언어 관습·지침이 모두 정렬** → baseline이 높다. 이 **headroom 판**에서 위반(camel) 선행을 늘렸을 때:

- 준수율이 **절벽**으로 떨어지면 → "선행 위반이 준수를 무너뜨린다"의 **깨끗한 증거**(바닥 아티팩트가 아님).
- 위반이 늘어야 준수율이 떨어지므로, prior 지속과 **구분**되는 조건이 된다.

## step A와 다른 것

| 축 | step A | **step3 · snake-4to0** |
|---|---|---|
| 지침 목표 표기 | camel | **snake** (Python 관습 정렬) |
| 선행 `n_compliant` (준수=snake) | 4/3/2/1/0 | 4/3/2/1/0 |
| 선행 `composition` | CLONE 12 | 동일 |
| 개입 | none | none |
| 반복 | seed 20 | seed 20 |

→ 5 × 20 = **100회**. `n_compliant`는 **준수(snake) 개수**이므로, 줄어들수록 위반(camel) 선행이 4→8→12로 늘어난다.

## 재는 것

준수율(첫 함수)·자기증폭(턴1→2→3)·위반 턴 분포. `snake-8to5`(준수 8/7/6/5)와 이어 **준수 8..0 전체 곡선**을 그려 절벽 위치를 확정한다.

| 결과 | 해석 |
|---|---|
